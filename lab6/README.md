# Лабораторная работа 6: Обработка пропущенных значений

## Описание

Лабораторная работа посвящена изучению методов обработки пропущенных значений в данных для задач машинного обучения.

## Цель работы

Изучить и применить различные методы обработки пропущенных значений, проанализировать их влияние на качество данных.

## Задачи

1. Загрузить и проанализировать датасет
2. Выявить пропущенные значения
3. Применить различные методы заполнения пропусков
4. Сравнить эффективность методов
5. Подготовить данные для дальнейшего анализа

## Структура проекта

- `lab6.ipynb` - Jupyter Notebook с полным анализом
- `lab6_data_cleaning.py` - модуль с функциями очистки данных
- `healthy_meal_plans_processed.csv` - датасет для анализа

## Используемые библиотеки

- numpy
- pandas
- matplotlib
- seaborn
- scikit-learn

## Запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите Jupyter Notebook:
```bash
jupyter notebook lab6.ipynb
```

## Результаты

Лабораторная работа демонстрирует:
- Анализ пропущенных значений в датасете
- Применение 4 методов обработки пропусков
- Сравнение методов и визуализацию результатов
- Подготовку данных для дальнейшего использования

## Выводы

Изучение методов обработки пропущенных значений критически важно для качественного анализа данных в машинном обучении.
